**Analyse et Prédiction des Mouvements du Marché de Bitcoin (BTC):**

Ce projet a pour objectif d'analyser et de prédire les mouvements du marché du Bitcoin (BTC) en utilisant des techniques avancées d'apprentissage automatique. Bitcoin est une monnaie numérique décentralisée qui permet des transactions peer-to-peer sans nécessiter d'autorité centrale. Ce projet utilise des modèles d'apprentissage supervisé et non supervisé pour fournir des prévisions sur les tendances du marché et les prix futurs de Bitcoin.

**Technologies et Outils Utilisés:**

Langage de programmation : Python

Bibliothèques :
pandas pour la manipulation de données
numpy pour les calculs numériques
scikit-learn pour les modèles de machine learning
matplotlib et seaborn pour la visualisation des données
keras et tensorflow pour les réseaux de neurones (si applicable)
yfinance pour l'extraction des données historiques du marché de Bitcoin

**Modèles Utilisés**

Ce projet intègre plusieurs modèles d'apprentissage automatique afin d'analyser et de prédire les tendances des prix du Bitcoin :

Apprentissage par Renforcement (RL) : Utilisé pour optimiser les stratégies de trading et prendre des décisions basées sur les récompenses des actions.

K-Nearest Neighbors (KNN) : Utilisé pour la classification des mouvements du marché en fonction de données similaires passées.

Decision Trees (DT) : Un modèle supervisé utilisé pour prédire les mouvements futurs en fonction des décisions prises sur les variables précédentes.

Random Forests (RF) : Utilisation d'un ensemble d'arbres de décision pour améliorer la précision des prédictions.

Méthodes Ensemblistes :
Bagging
Boosting
Stacking Ces techniques sont utilisées pour combiner plusieurs modèles et améliorer la performance du modèle final.
K-Means : Un algorithme de clustering utilisé pour identifier des groupes de comportements similaires dans les données de marché.
Support Vector Machines (SVM) : Un modèle de classification utilisé pour prédire les tendances des prix en fonction des données d'entrée.
